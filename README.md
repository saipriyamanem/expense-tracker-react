# Expense Tracker

A responsive Expense Tracker application built with React and Vite.

The application allows users to add, edit, delete, filter, and manage expenses while keeping data saved in the browser.

## Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Mark expenses as paid or pending
- Filter expenses by payment status
- Filter expenses by category
- View individual expense details
- Calculate total, paid, and pending amounts
- Store expenses using Local Storage
- Responsive design for different screen sizes
- 404 page for invalid routes
